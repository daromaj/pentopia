# Saved puzzles

Community/curated Pentopia puzzles, one JSON file per puzzle:

```json
{
  "url": "pentopia/10/10/2s9ziar5gbi6z6hai9s4//p",
  "name": "10x10, 10 clues, 2026-07-18",
  "addedAt": "2026-07-18T00:00:00.000Z"
}
```

Files here are typically added via the player's per-favorite **PR**
button, which opens GitHub's file editor pre-filled with the puzzle —
commit directly or open a pull request.
